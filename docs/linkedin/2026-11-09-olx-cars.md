curl, Python requests, even headless Chrome: three clients, three connection resets from OLX.

The block wasn't a captcha. It was the TLS handshake.

OLX drops anything whose TLS ClientHello doesn't look like a browser. Not with a captcha - with a connection reset, before a byte of HTML arrives. Chrome itself got reset. So did curl. So did Python requests.

curl_cffi with a Chrome impersonation got through: 200 OK, clean JSON. After that it was just reading their own search API. One dependency, no proxy, no account, no API key.

The tool is a CLI and an MCP server for used cars in India:

olxcars search "swift" --city chennai --min-price 300000 --max-price 600000 --year-min 2018

136 matching cars in Chennai, 20 per page, as JSON: price, year, km, fuel, transmission, owner count, city, seller type, photos, and the live listing URL.

The part that cost me the most time: OLX ignores unknown query parameters silently. A filter that doesn't exist looks exactly like a filter that worked. The only honest check was OLX's own applied_filters echo in the response, so the tool prints it on every run.

592 lines of Python for the tool, 152 for the tests. 8 tests - 5 offline, 3 live, including a full MCP round-trip. It installs as a Claude Code plugin with one command.

Try it: https://github.com/aswathas/olx-car-search
