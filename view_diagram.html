Code Mode vs MCP Architecture (OLX Cars)

Why Code Mode cuts token tax by 99.5% for data retrieval

1. The Problem: Traditional MCP Function Calling High Token Tax

Every page fetch dumps 20 raw ads (~40 KB JSON) straight into the LLM context. 3 pages = 120 KB (over 30,000 tokens) wasted just to find 3 cars.

2. The Solution: In-Memory Code Mode 99.5% Token Savings

The agent writes a 6-line script. Loops, pagination, and filtering happen inside local memory (RAM). Only the 3 selected cars enter LLM context.

3. The Exact Python Script That Powers Code Mode

from olxcars.client import OlxClient

client = OlxClient()
loc = client.resolve_city("Chennai", state="Tamil Nadu")[0]["id"]

# Fetch multiple pages inside RAM
candidates = []
for page in range(1, 4):
    res = client.search(query="i10", location=loc, transmission="automatic", max_price=400000, page=page)
    candidates.extend(res.get("cars", []))

# In-memory filter & sort (Zero LLM token cost)
top3 = sorted([c for c in candidates if c.get("owner") == "first"], key=lambda c: c.get("km", 999999))[:3]

# Only stdout enters LLM context!
for car in top3:
    print(f"{car['price_display']} | {car['year']} {car['title']} | {car['km']} km | {car['url']}")
